- 自动测试 135 项通过，覆盖结构化交接、引用约束、失败保留、图渲染失败、取消恢复及有限修正。

## 尚未解决

1. 模型审核仍可能漏报语义错误。合法引用不保证结论被引用行直接支撑。
2. 数据流程图可能把执行先后错误地表达成数据依赖。
3. 生成的范围说明可能与实际读过的源码不一致。
4. 协议重试、复核与修正可能挤占预算；系统需明确保留未通过状态。
5. 当前源码对应的新安装包尚未完成安装与完整任务验收，干净 Windows 环境也未验证。

## 数据边界

目标仓库只进行静态阅读，没有运行其服务；练习未执行或评分。应用运行时会把选中的公开仓库代码、学习目标及相关成果发送给配置的模型服务。密钥在 Windows 本地保存时由 DPAPI 保护；不要将自己的数据目录、环境文件或凭据提交到 Git。
