# 开发预览质量说明

本仓库公开当前源码，不宣称已达到稳定发布质量。

## 已验证

- 0.6.9 自动测试 146 项通过、无跳过；前端构建及进度状态回归通过。模拟模型测试不证明真实内容质量。
- 本轮真实模型审核校准 6 项中 5 项达到预期；正确条件用例因练习范围被误判而失败。全部失败记录保留。
- 0.6.9 已实际安装，完成设置、真实任务、引用查看、图表、导出、退出与重启恢复；使用独立数据目录并移除 Python/Node PATH。
- 同一安装版任务虽然自动状态为 succeeded，人工式源码复核仍失败。脱敏事实、提交、消耗和失败记录见 [收尾验收](FINISHING-ACCEPTANCE.md) 与 [结构化记录](acceptance-0.6.9.json)。

## 尚未解决

1. 模型审核仍可能漏报语义错误。合法引用不保证结论被引用行直接支撑。
2. 数据传递图可能遗漏返回对象的其他输入；渲染成功不保证数据语义正确。
3. 已由程序展示真实读取范围，但模型补充说明仍可能混淆“未展开解释”与“未读取”。
4. 协议重试、复核与修正可能挤占预算；系统需明确保留未通过状态。
5. 当前安装版操作链已验证，但未在没有开发环境的全新 Windows/虚拟机验证；安装包未签名，SmartScreen、干净机首次安装与卸载尚未验证。

## 数据边界

目标仓库只进行静态阅读，没有运行其服务；练习未执行或评分。应用运行时会把选中的公开仓库代码、学习目标及相关成果发送给配置的模型服务。密钥在 Windows 本地保存时由 DPAPI 保护；不要将自己的数据目录、环境文件或凭据提交到 Git。
