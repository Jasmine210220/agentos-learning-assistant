## 审查后修正

- 字段覆盖只检查标签中显式字段名，不验证来源、对象类型或边的语义。另有模型审核与逐条源码复核，不能仅凭字段出现通过内容验收。
- 装饰器与类名、函数头与 return 都必须处于可见区间。每次模型调用的语法记录按实际发送区间生成；原有 yield、赋值及副作用归属记录也按发送区间过滤。
- 仅目标唯一匹配、函数完整可见、单个显式 return 且全部为具名关键字参数时强制字段覆盖。多个返回、混合间接返回、位置参数、**kwargs 不产生合并契约；过长/过多字段保留静态记录及不强制检查的说明，不无限重试。
- 新任务范围说明由程序生成，保留读取失败、超限、文件树截断、代码段预算及静态未验证说明。目标范围不足的模型判断仍明确标注并阻止成功。原始模型输出保留在事件中，不改写历史任务或旧验收记录。
- 图表页和报告显示返回调用的字段表达式及源码引用；提示词约束标题中的不可变性、字符兼容性等无据断言。
- 字段遗漏复用既有一次绘图修正；仍遗漏不能成功。没有提高模型调用、token 或修正轮数上限。
